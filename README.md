# PrefixCalc

Инженерный калькулятор для электроники, который понимает приставки СИ: `10n * 100k = 1m`.

Сейчас это MVP в виде веб-приложения (PWA): работает в браузере на iPhone и Android и ставится на домашний экран. Вычислительное ядро (`src/si.js`) не зависит от UI и без изменений переносится в будущую нативную версию на React Native/Expo.

## Что умеет

- Приставки с учётом регистра: `p n µ(u) m k M G` (а также `f`, `T`, `K` как kilo). `m` означает милли, `M` означает мега.
- Число и приставка пишутся слитно или через пробел: `10n` и `10 n`.
- RKM-запись номиналов: `4k7` = 4.7k, `2u2` = 2.2µ, `4R7` = 4.7, `10R` = 10.
- Операторы `+ − × ÷ ^ √ ( )`, `1/x`, `π`, параллельное соединение `||`: `A || B = A·B/(A+B)`.
- Приоритет по ТЗ (от слабого к сильному): `+ −` → `× ÷` → `||` → `^` → унарные `−`, `√` → скобки и числа. Поэтому `10k || 10k * 2 = 10k`, а `-2^2 = 4`.
- Результат считается на лету и показывается в инженерной нотации (мантисса от 1 до 1000) с соседним порядком, обычной и экспоненциальной записью.
- Ручной сдвиг приставки (ENG ‹ ›, свайп по результату).
- Ближайший номинал из рядов E12/E24/E96 с погрешностью в процентах.
- История из 50 расчётов: тап вставляет результат, долгий тап вставляет выражение. Тап по результату копирует его.
- Своя клавиатура вместо системной, курсор тапом, кнопками ◀ ▶ или свайпом. Физическая клавиатура работает напрямую.
- Светлая и тёмная тема (чисто чёрный фон для OLED), работа офлайн.

## Запуск

```sh
npm test        # тесты парсера, включая таблицу приёмки из ТЗ (§4)
npm run build   # собирает dist/pwa/ (PWA) и dist/app.html
```

Чтобы попробовать PWA локально: `npx serve dist/pwa`, затем открыть адрес с телефона в той же сети. Для установки на iPhone нужен HTTPS (например, GitHub Pages): Safari → «Поделиться» → «На экран „Домой“».

## Структура

| Путь | Что там |
| --- | --- |
| `src/si.js` | Парсер, вычисление, форматирование, E-ряды. Без зависимостей. |
| `test/si.test.js` | Тесты на `node:test`. |
| `web/app.src.html` | Интерфейс. При сборке в него встраивается `src/si.js`. |
| `scripts/build.js` | Сборка PWA. |
